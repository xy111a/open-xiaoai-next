## 1. 安装经过（供复现）

1. 首次 `go install ...@latest` 在 240s 超时时仍在下载依赖，未完成。
2. 第二次（570s 超时）编译失败：`compile: writing output: no space left on device`——
   原因是 Go 编译临时目录默认走 `/tmp`（本机 tmpfs 仅 512M），与网络无关。

   注意：`go install` 下载的 `golang.org/x/crypto` 等依赖较大，复现时请同样设置
   `GOTMPDIR` 到家目录（128G 空闲），不要用默认 `/tmp`。

补充说明：

- G104 是 gosec 新版才报的规则（旧版 14 项清单里没有）：它把“拆除中的
  `Close()` 不判错”全部算作发现；仓库的 `errcheck`（golangci）对这类
  `_ =` 显式忽略是放行的，裸 `Close()` 与 `_ = Close()` 语义相同。
  如后续想消掉这类噪音，统一改成 `_ = conn.Close()` 即可，不改行为——
  本轮未动（不在 H-10 的修码范围，只做裁决）。
- G706 同样是新版污点分析规则：6 处全是“请求来源数据进本地日志”，
  无敏感数据外泄、无注入到执行路径；真要修也只是日志前 strip 换行，
  收益低，留待后续。
- 旧清单里的 G402（transport MinVersion）已消失，可直接用本次扫描复核：
  `transport.go` 的 `tls.Config` 现含 `MinVersion: tls.VersionTLS12`（H-8）。
